# Agent Fieldnotes

具身智能能力探索展厅：精选完成的仿真演示，探索模型、规划、记忆与动作学习如何配合。

访问网站：https://glaz-j.github.io/agent-fieldnotes/

静态页面位于 `docs/`，使用 GitHub Pages 从 `main` 分支的 `/docs` 目录发布。无需后台或 API 密钥。支持卡片静音悬停预览、项目版本切换与视频分享链接。

## 内容范围

本仓库仅包含精选页面、页面实际引用的图像与录像、技术路线解读和上游署名。完整研究记录、未入选轨迹、原始模型请求、凭据、权重和数据集均未包含。

本展厅用于展示完成的操作与探索有趣的方法，不提供完整基准排名。在线语言决策、模型生成的固定代码、预训练策略、经典控制与人类示范均分别标注。

## 更新

修改 `docs/` 内的静态文件并推送到 `main` 后，GitHub Pages 自动发布。所有站内路径相对站点根目录，适用于项目路径 `/agent-fieldnotes/`。
