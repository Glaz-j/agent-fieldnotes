# 第 1 章：机器人 Agent 由什么组成

你在展厅里看到机械臂抓起积木、移动到容器上方、松开夹爪。动作很连贯，但仅凭录像，我们还不知道下一步是预先写好的，还是模型根据新画面临时决定的。课程的第一项能力，就是沿着一次操作找出每个决定的来源。

本章不要求安装环境。你只需要会阅读简单 Python 函数；实验是观察案例、画出系统结构，并给一个任务写验收条件。

## 本章目标

学完后，你应能解释任务、观察、决策、技能、控制和验收之间的关系；能够区分固定脚本、规则闭环与在线模型决策；还能说明“机器人动了”“工具返回成功”和“任务完成”为什么是三件事。

## 从一个可检查的任务开始

我们先采用一个小任务：把红色方块移到蓝色目标区。这里至少有三个条件：操作的是指定物体、物体进入指定区域、机械臂已经释放物体。若机械臂只是夹着方块经过目标上方，不能算完成。

任务描述给出了希望发生的变化，验收函数把变化变成可以检查的条件。例如，最初可以用仿真中的方块位置判断它是否进入目标区。这是教学阶段的精确判定，后续才讨论视觉误差。写清条件，比给任务起一个宏大的名字更有用。

## 一次操作中的六个环节

| 环节 | 输入与输出 | 需要回答的问题 |
| --- | --- | --- |
| 任务 | 人的要求 → 目标和约束 | 操作什么，放到哪里，什么叫完成？ |
| 观察 | 传感器或仿真 → 当前信息 | 现在能看到什么？信息是何时取得的？ |
| 决策 | 任务和观察 → 下一步动作 | 该找物体、移动、抓取，还是停止？ |
| 技能 | 动作及参数 → 一段执行过程 | 怎样把“到达这个位置”转换成机器人运动？ |
| 控制与仿真 | 控制目标 → 状态变化 | 关节是否真正到位，物体发生了什么变化？ |
| 验收 | 执行后的观察 → 结果 | 目标是否达成，是否需要纠正？ |

决策不必覆盖每个物理仿真步。上层可以选择“移动到方块上方”，技能内部再完成多个控制步。把高层目标与底层执行分开，能让我们分别检查语言理解、动作参数和控制误差。

但分层不是一条固定规定。有的系统输出技能名称，有的输出末端路点，有的生成一段程序，有的直接输出动作序列。阅读一个项目时，先找到它的动作接口，再讨论模型“控制了什么”。

## 三种会动的系统

固定脚本按预设顺序调用动作。只要场景与假设一致，它就可能很好用；若方块换了位置，旧坐标可能失效。

规则闭环在动作之间检查状态。例如，没抓住就重新靠近。它能够纠错，但下一步由人写的规则决定，不能因此称为在线大模型 Agent。

在线模型决策把当前观察交给模型，由模型选择下一步，再将执行结果返回模型。模型调用、输入、动作和反馈应该能够在日志里追踪。一次模型生成后反复执行的固定程序，也要与每步重新调用模型区别记录。

课程默认实验先提供确定性的脚本或规则示范，让大家不需要密钥也能理解控制流程。在线模型入口会在第 6 章单独讲解。我们比较两种模式的行为，但不把离线演示包装成真实模型调用。

## 案例阅读：目标容器移动以后

打开 [MemS 目标移动案例](../gallery.html#demo-mems-target-shift-libero-three)。这是已有的案例阅读材料，课程实验包不等同于该项目的完整复现。

先观看第一次目标定位，再找到目标被移动后的片段。记录三个问题：系统在什么时刻获得新观察？旧位置是否仍参与后续动作？重新定位后，哪一个动作改变了？如果录像或说明没有给出某个信息，就在记录中写“材料未提供”，不要靠动作流畅程度补出推理过程。

然后阅读 [PyRUA-Lean 代码单元案例](../gallery.html#demo-pyrualean-astra-cells-20261028)，观察一次模型输出是否包含多个动作和局部检查。这样的执行方式能帮助我们理解：模型调用次数、技能调用次数与仿真步数是不同的计量单位。

## 动手任务：给系统画一张责任图

新建一份自己的学习笔记，写下“红色方块进入蓝色目标区”的任务，并完成以下工作：

1. 画出“任务 → 观察 → 决策 → 技能 → 执行 → 新观察”的循环，把验收放在适当位置。
2. 为每个环节写一个可能的错误：认错物体、坐标用错、抓空、提前宣布完成等。
3. 为每个错误选择要检查的证据。识别错误看输入画面和对象判断；控制错误看目标与实际状态；提前停止看终止前的检查结果。
4. 给两个展厅案例分别标注模型的输入、动作接口和已有材料能够证明的范围。

验收时，你应能用一句话说明每个模块的责任，并且能回答：如果完全去掉语言模型，系统中哪些部分仍然有用？答案应该包括仿真环境、技能、状态记录和任务验收。

## 常见误解

“看见机械臂完成一次任务，所以系统很可靠”忽略了失败尝试和初始条件。课程后面会要求保存所有指定测试的结果。

“模型说完成了，所以完成了”把系统的判断当成了外部事实。终止前应有可检查的证据。

“技能越复杂越先进”也不成立。复杂技能可能把感知和恢复藏在内部。选择什么粒度，要看我们希望学习和比较哪一层。

## 练习

基础题：把任务改成“把两个方块按颜色分类”，补充三个新的验收条件。挑战题：设计一个录像看起来成功、实际不符合任务条件的例子，并说明哪项观测能揭示它。
