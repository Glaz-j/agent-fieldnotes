# 第 8 章：从 RGB 图像估计位置

前面的控制器能直接读取仿真坐标，这是精确状态输入。本章换一个入口：只从渲染图像寻找颜色，再利用已知相机几何估计位置。你将亲眼看到，“检测到了”与“定位足够准”之间还有距离。

前置要求：完成第 3 章观察来源与第 4 章坐标学习，能够运行环境自检。本章提供独立视觉练习；当前 `scripted` Agent 仍使用状态观察，不能把本章结果写成已经完成了纯视觉动作闭环。

## 本章目标

生成一张实际 RGB 图像，读出红方块和蓝区域的像素位置，理解像素到世界坐标的转换，并用仿真真值独立评价误差。真值只在最后评价时使用，不参与颜色检测和位置预测。

## 第一步：运行并查看真实图像

在仓库根目录、激活课程 Python 环境后执行：

```sh
python lab/run.py vision --seed 7 --out runs/ch08-vision
```

输出目录包含 `top-camera.png` 和 `vision.json`。用本机图片查看器打开 PNG，找到红方块、蓝区域与机械臂。不要跳过图像直接相信坐标：机械臂可能遮住大部分红色表面，而程序仍能找到剩余像素。

检查 JSON 中的 `source`。它应说明结果来自颜色掩码与已标定平面，而不是仿真对象坐标。`scope` 也明确限制了实验：这是受控颜色定位，不是通用 VLM，不是完整视觉策略。

## 第二步：像素怎样变成目标候选

当前实现分别取出 RGB 三个通道。红色候选需要红通道足够亮，并明显强于绿色与蓝色；蓝色候选采用对应规则。满足条件的像素组成掩码，再分别取横纵坐标的中位数作为代表位置。

注意这里是像素坐标的中位数，不是三维物体中心。少于 20 个候选像素时，程序返回 `color_not_visible`；超过阈值时的 `ok` 只表示得到一个候选。它既不保证对象完整可见，也不保证误差符合抓取要求。

颜色规则适合当前单红块、单蓝区域、固定光照的场景。如果出现两个红物体，全部红像素的中位数可能落在两者之间；如果物体被遮挡，代表位置可能偏向剩余可见部分。这些问题不能靠把返回值改成“置信度 0.99”解决。

## 第三步：为什么一个像素还不够

针孔相机将世界点投影到像素；反过来，一个像素通常对应一条射线，而不是唯一三维点。恢复位置需要额外信息，例如深度或已知平面。内参描述焦距与主点，外参描述相机与世界之间的关系。[OpenCV 官方相机几何说明](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html)

本实验采用固定俯视相机，图像为 640 × 480，相机高度 1.4 米，垂直视场角为 48°。程序预先知道红块顶面与蓝区域顶面的高度，因此可以把像素射线与对应水平面相交。

对于这一特定相机，转换可以写成：

```text
f = 480 / (2 × tan(48° / 2))
d = 1.4 - 已知平面高度
x = (u - 319.5) × d / f
y = -(v - 239.5) × d / f
z = 已知平面高度
```

图像的纵坐标向下增长，所以世界坐标的 `y` 带负号。红块使用 0.044 米顶面，蓝区域使用 0.014 米顶面。这里的高度是明确给定的先验，并不是从单张图片推断出来的。移动相机、改变分辨率或改变物体高度后，必须重新处理几何关系。

## 第四步：独立测量定位误差

运行以下完整检查程序。它先读取已经生成的视觉预测，再重新建立相同种子的场景，仅取真值作为评价标签：

```sh
python - <<'PY'
import json
import math
import sys
from pathlib import Path

sys.path.insert(0, "lab")
from run import World

predictions = json.loads(Path("runs/ch08-vision/vision.json").read_text())
world = World(seed=7)
truth = {"block": world.block, "goal": world.goal}
tolerance_m = 0.01
for kind in ("block", "goal"):
    result = predictions[kind]
    if not result["ok"]:
        print(kind, "未检测到：", result["error"])
        continue
    error = math.dist(result["xyz"][:2], truth[kind][:2])
    print(kind, "像素数：", result["pixels"])
    print("像素位置：", result["pixel_uv"], "估计位置：", result["xyz"])
    print(f"平面误差：{error:.5f} m；满足 1 cm 标准：{error < tolerance_m}")
PY
```

只比较 `x, y`，因为视觉返回顶面高度，而仿真物体位置是物体坐标原点；直接比较两者的 `z` 会混入定义差异。这里的 1 厘米是练习预先设定的定位标准，不是代码自动承诺的精度。

如果红块检测成功却没有通过误差标准，回到图像检查遮挡，并记录结果。一次未达标的定位同样是有效实验：它揭示了当前方法的适用边界。不要先看到误差，再临时放宽标准使结果通过。

## 视觉怎样才能进入决策

位置估计交给控制器前，还需要确认目标身份、坐标系、可见性和误差是否可接受。没有找到目标时，应重新观察或结束当前尝试；一个可见性失败不能被替换成旧的真值坐标而仍称“纯视觉”。

当前课程停在可复现的定位与误差评价。把估计位置接入运动、执行后重新感知并处理遮挡，是后续扩展任务。单独保存一张图片并不意味着决策已经使用它。

## 本章验收与排查

提交原图、视觉 JSON、两项平面误差和对遮挡的解释。验收重点是正确区分预测与评价标签；不要求每个目标必然通过 1 厘米标准。

渲染报错时先查看 `doctor` 的渲染项；没有 RGB 图像就没有完成本章。`color_not_visible` 时检查是否遮挡、亮度或颜色条件不符。位置整体镜像时检查图像纵轴方向；位置按比例偏移时检查焦距、图像尺寸与已知平面。不要将这些错误笼统归因于“模型幻觉”。
