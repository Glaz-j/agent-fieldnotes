更新：2026-11-10。尚未提交。以下对应官方立项表的六个字段，提交事项见 [提交前说明](submission-notes.md)。现有仓库名：`agent-fieldnotes`。

## 项目简介

《动手学机器人 Agent》（Agent Fieldnotes）是一套面向具身智能前沿的中文实践教程，以“构建能观察、决策、行动、验证和恢复的机器人 Agent”为主线，将机器人基础、Agent 系统设计与可复现实验贯通起来。

课程以桌面方块搬运为贯穿任务，通过16章教材，从观察、坐标和技能接口逐步进入任务规划、视觉定位、任务与空间记忆、主动观察、程序化计划、局部技能学习和对照评测，最终完成双物体搬运助手。读者在每一步运行代码、观察行为、分析结果，掌握从单次动作到连续完成任务的系统构建方法。

项目已提供在线教材、基于 MuJoCo 的轻量本地实验包和嵌入正文的演示。基础路线可在普通个人电脑上离线完成，无需实体机器人、GPU或付费模型API；进阶内容衔接模型工具接口与前沿机器人 Agent 方法。

在线课程：https://glaz-j.github.io/agent-fieldnotes/
仓库：https://github.com/Glaz-j/agent-fieldnotes

## 立项理由

### 补齐 Datawhale 具身课程中的机器人 Agent 实践路线

从现有公开课程目录来看，Datawhale 的具身智能教程主要围绕传统机器人方法与模型学习路线展开，重点覆盖运动学、控制、运动规划、强化学习和模仿学习，并拓展到 VLA、世界模型等方向。相比之下，以 Agent 为核心，系统讲解任务分解、工具调用、记忆管理、执行验证与失败恢复的机器人实践内容仍然较少。学习者已有丰富的基础知识和模型学习入口，还需要一条把这些能力组织成完整机器人 Agent 的连续实践路径。[现有理论课程](https://datawhalechina.github.io/dive-into-embodied-ai/docs/foundations/intro) · [现有实战项目](https://datawhalechina.github.io/dive-into-embodied-ai/docs/practices/intro)

前沿研究已经给出了明确的实践信号：在 RoboDojo 上，PyRUA-Lean 通过语言模型逐步编写 Python、调用感知与运动工具，并结合环境反馈推进操作；RoboMME 榜单也已设置 Agentic 赛道，将 Agent 系统纳入机器人评测视野。这些进展表明，机器人能力建设正在拓展到模型、工具、记忆与执行反馈的系统协同。理解这条路线，需要一套可以亲手搭建、观察和验证的学习路径。[PyRUA-Lean / RoboDojo](https://dagroup-pku.github.io/PyRUA-Lean/docs/robots/robodojo/) · [RoboMME 榜单](https://robomme.github.io/leaderboard.html?benchmark=plus)

《动手学机器人 Agent》围绕这一需求建立完整教学主线：用同一个桌面任务串起机器人基础与 Agent 核心机制，让读者从运行第一个仿真环境出发，逐步掌握技能调用、目标表达、反馈控制、失败恢复、记忆和实验评估。课程把前沿系统中的关键问题拆成可运行的小实验，为进一步阅读研究代码、接入模型与扩展任务建立基础。

本项目将为 Datawhale 现有具身课程补上机器人 Agent 系统实践这条学习主线，连接经典机器人基础、模型能力与新一代 Agent 方法，帮助学习者从理解单个模块走向构建完整系统。现有16章教材、实验包与课程演示为共建提供了基础；通过社区协作校审和组队学习，持续完善这套面向前沿方法、可动手实践的中文开放课程。

## 项目受众

项目面向具备 Python 基本语法、准备进入机器人与具身智能方向的高校学生和开发者，以及已有文本 Agent 开发经验、准备将 Agent 能力延伸到物理任务的学习者。

课程提供清晰的起步路径：通过“开始之前”准备页熟悉终端、文件路径，以及变量、函数、字典、循环与判断，再进入仿真实验。零编程基础读者可先完成配套链接中的 Python 基础练习。机器人学、强化学习和模型接口所需知识随章节逐步引入。

课程学习目标是让读者独立运行机器人任务、设计可检查的目标、编写与修改技能循环、分析执行日志、实现记忆与失败恢复，并完成双物体任务的实验与验收报告。

## 项目亮点

### 项目创新与特色

本项目围绕机器人 Agent 的系统构建，形成“任务贯穿、闭环递进、失败驱动、证据配套”的教学设计，将前沿 Agent 方法中的关键系统问题转化为初学者可以亲手完成的实验。

1. **课程主线创新：以 Agent 闭环组织机器人知识。** 围绕“观察—决策—技能调用—结果验证—记忆更新”安排16章内容，将坐标、控制、视觉、规划与学习连接到明确的任务需求。读者既理解每个模块，也理解它如何参与一个持续运行的机器人系统。
2. **递进实验创新：同一任务伴随能力升级。** 从单物体搬运到双物体整理，逐步引入反馈、恢复和记忆；视觉、主动观察、程序化计划与局部技能学习提供配套专项实验。熟悉的场景让每次新增机制及其作用更容易辨认，减少反复适应新平台的负担。
3. **失败驱动教学：把恢复能力作为核心学习目标。** 将抓取失败、目标移动、记忆过期与观察不足设计成教学问题。读者先预测行为，再运行对照、定位原因、调整策略，用实验理解机器人在不确定环境中如何继续完成任务。
4. **教材、演示与执行证据联动。** 正文嵌入9处演示，其中5段课程实际仿真录像配有字幕和动作记录，其余展厅案例配合章节问题讲解。代码、画面、日志与成功条件相互对应，让读者能够追踪一次决策如何影响动作与最终结果。
5. **轻量可复现的实践路径。** 基于 MuJoCo 提供可在个人电脑离线运行的实验包，将安装自检、预期输出、练习解释、对照评测与毕业验收纳入课程。读者可以用低成本环境掌握系统机制，再延伸到模型接口和更复杂的机器人平台。

### 同类项目调研与差异

- [Datawhale《动手学具身智能》](https://datawhalechina.github.io/dive-into-embodied-ai/)覆盖具身基础、控制、强化学习、VLA、ROS2与多类实践。本项目以机器人 Agent 的决策与执行闭环为主线，将跨章节知识汇入一个持续演进的任务，形成聚焦系统构建的实践课程。
- [Datawhale Hello-Agents](https://github.com/datawhalechina/hello-agents)系统介绍 Agent 范式、框架、记忆与评估。本项目将这些能力落实到具有坐标、运动约束、物体状态和动作失败的仿真环境，建立从 Agent 决策到物理结果的完整教学链路。
- [Software Carpentry · Programming with Python](https://swcarpentry.github.io/python-novice-inflammation/)以小例子、预期输出和练习帮助新手入门。本项目将“先预测—再运行—核对解释”的教学方法融入机器人实验，使每次运行都对应可观察的行为和可回答的问题。

上述设计共同构成本项目在机器人 Agent 教育中的创新：把系统构建、故障诊断和实验评估纳入同一条递进学习路径，让读者具备理解前沿方法、动手实现机制、独立验证结果的能力。
